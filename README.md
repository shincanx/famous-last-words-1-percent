Entry for the [make.fun bounty "Famous Last Words at 1 Percent"](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4) — the funniest possible last words a phone would say when its battery hits 1 percent, as a single line of at most 199 characters.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` and prints it to stdout. No network, no dependencies, deterministic.
